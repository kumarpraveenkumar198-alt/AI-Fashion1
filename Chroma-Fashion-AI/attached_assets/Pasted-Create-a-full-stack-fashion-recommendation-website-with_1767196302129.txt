Create a full-stack fashion recommendation website with a modern e-commerce style UI similar to Myntra or H&M.

TECH STACK:
- Backend: Python (Streamlit)
- Frontend styling: Custom HTML/CSS embedded in Streamlit
- AI: OpenCV + basic ML for skin tone analysis
- Image upload only (no webcam)

WEBSITE UI REQUIREMENTS:
- Landing page with:
  - Large hero section (banner-style) with gradient background
  - Fashion tagline like “Find Colors That Match You”
  - Call-to-action button: “Analyze My Style”
- Navigation bar with sections:
  - Home
  - Style Analyzer
  - Color Guide
  - About
- Use card layouts, rounded corners, shadows, and smooth spacing
- Add sliders/carousels using Streamlit components to:
  - Show trending outfit color palettes
  - Show seasonal fashion colors
- Add product-style cards (like Myntra):
  - Outfit image placeholder
  - Color name
  - Skin tone suitability badge
- Use modern fonts, pastel gradients, and clean spacing
- Overall look should feel like a fashion e-commerce website, not a basic ML demo

AI FUNCTIONALITY:
- User uploads a face image
- Detect face using OpenCV Haar Cascade
- Extract facial skin region
- Convert to HSV color space
- Compute average or dominant skin color
- Classify:
  - Skin tone: Light / Medium / Dark
  - Undertone: Warm / Cool / Neutral
- Based on results, recommend outfit colors using rule-based logic

RESULT PAGE:
- Show:
  - Uploaded image with detected face box
  - Skin tone & undertone results in stylish info cards
  - Recommended color palettes as clickable or visual color tiles
  - Outfit suggestions displayed like product cards
- Add confidence score or percentage for recommendations

OTHER REQUIREMENTS:
- Handle errors gracefully if no face is detected
- Keep the code modular and well-commented
- Main file name: app.py
- Use opencv-python-headless
- Make the UI visually impressive and submission-ready

GOAL:
The final output should feel like a real fashion recommendation website inspired by Myntra/H&M, powered by AI, suitable for academic demonstration and portfolio use.
